# 2026-05-27

- BataMart production issue: marketplace feed showed products, but product detail pages displayed "Product not found" and sell page failed with "Failed to create product".
- Root cause was schema drift: Prisma `Product` model expected `deliveryEstimate`, but Supabase `public.Product` was missing the column. Feed endpoint kept working because it used a narrow `select` that did not include `deliveryEstimate`; detail/create touched the full Product shape and failed with Prisma P2022.
- Fixed by adding migration `20260527133000_add_missing_product_delivery_estimate` with `ALTER TABLE "public"."Product" ADD COLUMN IF NOT EXISTS "deliveryEstimate" TEXT;`, applying it with `prisma db execute`, then recording it with `prisma migrate deploy`.
- Verification: full product detail Prisma query succeeds for active product `cmok5zxha0002r66lp51e2kd0`; `npm run build` passes; `prisma migrate status` reports schema up to date.
- Follow-up: sell page still failed because `Product.moderationStatus` existed as text but Prisma expected enum type `public.ProductModerationStatus`, which did not exist. Added and applied migration `20260527142000_fix_product_moderation_status_enum` to create the enum and convert the column. Rollback product-create diagnostic succeeded; no fake product persisted.
